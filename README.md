# Accounting-

سامانه حسابداری فروش، خرید و تسویه کارگاه با رابط فارسی/RTL و معماری local-first.

## UI checkpoint — 2026-09-13
صفحات اصلی سامانه به رابط اجرایی متصل شده‌اند: داشبورد، اشخاص، کالاها، تاریخچه قیمت، فروش، دریافت و چک، موجودی، تولید، خرید، پرداخت، هزینه‌ها، سرمایه و شرکا، حساب جاری و تنظیمات. عملیات پیشرفته شامل انتقال انبار، فرمول تولید، مرجوعی فروش/خرید، خزانه، درآمد، کارکنان/حقوق و جایگزینی چک نیز در لایه رابط فعال شده‌اند.
